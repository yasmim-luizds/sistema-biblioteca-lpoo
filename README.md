# Sistema de Biblioteca em Java

Projeto desenvolvido para a disciplina de **Linguagem de Programação Orientada a Objetos**, com o objetivo de aplicar conceitos de orientação a objetos em um sistema de gerenciamento de biblioteca.

---

## Sobre o Projeto

O sistema permite realizar o controle básico de uma biblioteca, incluindo cadastro de livros, cadastro de usuários e gerenciamento de empréstimos.

A aplicação foi desenvolvida em **Java**, com interface gráfica utilizando **Swing**, e utiliza arquivos `.txt` para armazenar os dados do sistema.

Durante o desenvolvimento, foram aplicados conceitos de **Programação Orientada a Objetos**, como herança, polimorfismo, encapsulamento e abstração.

---

## Funcionalidades

- Cadastro de livros
- Cadastro de alunos e professores
- Login de usuários
- Listagem de livros
- Listagem de usuários
- Solicitação de empréstimos
- Aprovação de empréstimos
- Registro de devoluções
- Consulta de empréstimos

---

## Tecnologias Utilizadas

- Java
- Java Swing
- Maven
- Arquivos `.txt`
